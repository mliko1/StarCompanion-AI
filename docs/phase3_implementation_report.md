# 第三阶段实施报告

## 一、阶段目标
在第二阶段（姿态识别、举手、拍手、训练任务原型）基础上，实现：
1. 人与目标物品交互识别；
2. 连续行为步骤识别；
并打通"找到玩具 → 拿起玩具 → 放入收纳盒"生活技能任务的完整链路。

## 二、新增模块

### 1. vision/object_detector.py — 目标物品检测
- 技术：ultralytics YOLO yolo11n（COCO 预训练 80 类，CPU 实时）。
- 输入：摄像头帧；输出：类别、边界框、置信度、中心点。
- 诚实声明：COCO 无"盒子"类，收纳盒无法直接识别，需自训练（列入后续工作）。
- 实测：FPS 约 15（CPU），满足实时要求。

### 2. vision/interaction_detector.py — 人-物交互识别（规则判断）
- 输入：姿态关键点 + YOLO 检测框。
- 输出四态 + 不确定：approaching / touching_candidate /
  picking_candidate / placing_candidate / uncertain。
- 核心：手靠近 ≠ 拿起。"拿起"必须同时满足 疑似接触 + 物品中心位移
  超阈值；条件不足一律输出 uncertain。
- 多帧投票（8 帧窗口 ≥5 帧）+ 目标短暂丢失宽限期（0.5 秒）。

### 3. vision/behavior_sequence.py — 连续行为步骤识别（FSM）
- 5 步骤状态机：find→approach→pick→move→place。
- 每步含完成条件、超时（30~45 秒）、不确定处理、时间戳。
- 超时不判失败，只记"不确定"；支持暂停/恢复、任务重开；不自动判定成功。
- 单元测试 5 项全过（tests/test_behavior_fsm.py）。

### 4. vision/skill_task_session.py — 系统集成
- 链路：摄像头 → 姿态识别 + 物品检测 → 交互判断 → FSM → 记录。
- 道具命令行参数化：--target / --containers。
- 记录：data/sequence_logs/ JSON 明细 + CSV 汇总。

### 5. server/ — FastAPI 后端 + SQLite
- 任务库、训练记录、统计报表三个 API（/api/tasks、/api/records、/api/stats）。
- 历史 CSV/JSON 自动导入 SQLite（data/xingban.db）。

### 6. web/ — 家长管理看板（ECharts）
- 概览卡片 + 各任务完成柱状图 + 分类饼图 + 趋势折线 + 记录明细表。
- 说明：为降低部署复杂度先做静态单页（原生 JS + ECharts），
  正式版可迁移 Vue3（报告技术栈一致）。

### 7. vision/dtw_similarity.py — 动作相似度（DTW）
- 用于"模仿动作"评分，对动作速度/长度差异不敏感；单元测试 4 项全过。

## 三、技术结论（调试实证）
1. 识别用原始帧，显示用镜像帧（左右手判定依赖）。
2. 快慢动作分策略：持续动作重平滑+长防抖，瞬时动作原始信号+短确认。
3. 迟滞门槛 + 骤降特征（真拍手指纹）过滤慢速漂近的假动作。
4. 阈值必须实测标定（拍手 0.55/0.80、移动 0.12 屏宽、放入 1.6 倍框）。

### 8. core/decision.py — 提示依赖感知的个体化辅助决策（创新点 4.1）
- 五级提示等级：0独立 / 1视觉 / 2语音 / 3动作示范 / 4家长协助。
- 提示依赖指数 PDI = Σp/(4N)，独立完成率 = 独立完成次数/有效次数。
- 规则决策引擎：据完成率、PDI、独立完成率、趋势、不确定比例，
  生成 5 类可解释建议（保持/降低/辅助/观察/确认）。
- 伦理边界：建议仅供辅助参考，不形成诊断结论；用模拟数据验证
  （报告 7.3 允许），不冒充真实儿童记录。
- 单元测试 tests/test_decision.py 7 项全过。

## 四、已知局限（如实标注）
- 单目 2D 方案：精度为行为记录级，非医学测量级。
- 收纳盒等自定义物品需自训练 YOLO。
- 规则判断非深度学习模型，文档与演示中均明确标注。
- LSTM/TCN 时序模型、上下文多臂老虎机个体化决策：需长期真实数据积累，
  本阶段仅架构预留。
