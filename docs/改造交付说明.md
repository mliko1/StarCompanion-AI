# 星伴AI 网页系统改造 · 交付说明（含升级建议落实）

本系统从「Python 命令行脚本 + 静态看板」升级为
「FastAPI 后端 + SQLite 规范数据库 + Vue3 网页 + 多步骤任务理解 + 硬件/桌面端框架」，
支持电脑运行、手机/平板局域网访问。

> 原有视觉算法全部保留；被替换文件均备份为 `.bak`。

---

## 一、已实现功能

1. **统一摄像头服务**：全局只开一次摄像头，后台线程采集 + MediaPipe 姿态识别；
   原始帧用于识别（左右手正确）、镜像帧用于网页显示。
2. **训练控制**：开始 / 暂停 / 恢复 / 结束，实时显示识别状态。
3. **多步骤任务理解（核心）**：`把积木放进收纳盒`端到端任务已接入网页训练——
   YOLO 物品检测 + 人-物交互识别 + 连续行为 FSM（寻找→接近→拿起→移动→放入）。
4. **统一视觉事件格式**：事件类型/名称/时间戳/置信度/关联步骤，写入内存缓冲与数据库。
5. **规范数据库 11 表**：AI 识别与人工确认分开存储，提示等级带 CHECK 约束。
6. **报告统计**：训练次数、完成率、PDI、独立完成率、提示分布、场景表现、趋势。
7. **Vue3 网页 5 页面**：适配电脑与手机。
8. **硬件/桌面端框架**：ESP32 智能交互盒串口控制器、PySide6 儿童训练端（待硬件联调）。
9. **个体化适应**：每个孩子×每个任务逐步建立个体化参考范围（惯用手/幅度/时长/速度容差），
   首次训练仅记录待确认、多次训练 + 人工审核才收敛，不确定识别结果自动标记交家长/老师确认。
   已接入训练主循环——动作类：惯用手镜像 + 保持时长缩放 + 幅度缩放（dy_ratio/ratio 阈值）
   + 速度缩放（拍手骤降时序）；技能类：步骤超时缩放 + 惯用手优先追踪（InteractionDetector）。
   提供接口 `GET /api/personalization/profiles`、`POST /api/personalization/confirm_hand`；
   真机标定采集脚本 `vision/collect_calibration.py`（采集 dy_ratio/angle/ratio 供阈值标定）。

## 二、数据库设计（12 张表，表名与升级文档一致）

| 表名 | 作用 |
|---|---|
| `child_profile` | 匿名儿童档案 |
| `task_definition` | 训练任务定义（含任务版本） |
| `task_step` | 任务步骤 |
| `scene_info` | 家庭场景 |
| `training_session` | 训练记录 |
| `step_event` | 步骤事件（动作/步骤判定） |
| `prompt_record` | 提示等级变更记录 |
| `vision_result` | AI 视觉识别原始结果（含数据质量） |
| `manual_review` | 人工确认记录（与 AI 结果分开） |
| `analysis_result` | 分析结果（辅助建议） |
| `model_version` | 模型版本 |
| `personal_profile` | 个体化档案（惯用手/幅度/时长等参考范围，逐步建立） |

## 三、目录结构（新增/修改）

```
├── services/                     # 业务服务层
│   ├── camera_service.py         统一摄像头（原始帧识别 + 镜像帧显示）
│   ├── training_service.py       训练调度（支持 action / skill 两类任务）
│   ├── report_service.py         报告统计
│   ├── vision_events.py          ★统一视觉事件格式 + 事件缓冲
│   └── device_service.py         ★ESP32 设备服务
├── api/                          # 接口路由（training/camera/reports/personalization）
├── core/                         # 纯逻辑（decision 决策 / plan 方案 / personalization 个体化）
├── database/                     # SQLAlchemy 模型 + CRUD + 种子（12 表对齐文档）
├── hardware/esp32_controller.py  ★ESP32 串口控制器（框架）
├── desktop/main_window.py        ★PySide6 儿童训练端（框架）
├── server/                       # FastAPI 入口（0.0.0.0 + CORS）
├── frontend/                     # Vue3 前端（训练页支持多步骤进度显示）
└── vision/                       # 原视觉算法（全部保留）
```

★ 为本轮升级新增。

## 四、如何运行

```powershell
# 1. 启动后端（双击「启动训练系统.bat」或执行）
.\.venv\Scripts\python.exe -m server.run

# 2. 电脑访问
http://127.0.0.1:8000

# 3. 手机/平板（同一 Wi-Fi）
http://电脑IP:8000   # ipconfig 查「IPv4 地址」
```

前端已构建（`frontend/dist/`），后端直接托管；改前端后 `cd frontend && npm run build`。

## 六、注意事项（如实说明）

1. **多步骤任务需真实道具**：YOLO 用 COCO 预训练模型，不能识别「收纳盒」，
   需用碗/书/杯等 COCO 可识别物品替代（已如实标注，未虚构能力）。
2. **硬件/桌面端为框架**：ESP32 需实物硬件 + 固件联调；PySide6 需安装后测试。
3. **AI 识别仅供辅助**，不形成医学诊断，建议须经专业康复人员审核。
4. 后端冷启动约 6–12 秒（建库 + 种子数据），属正常。
